== Sonstiges
* Optik der Anwendung
- Kontrast nicht hoch genug auf manchen Seiten (schwarze Schrift auf dunklem Hintergrund), weswegen man die Texte nicht lesen kann bsp: http://localhost:8080/booking/{id}
- http://localhost:8080/events/{id} auf der Seite und allen anderen ist die Beschreibung abgeschnitten
- http://localhost:8080/my-hotels Zeilenumbruch beim Namen + Location wird nicht richtig angezeigt
- http://localhost:8080/ € und EUR gleichzeitig geschrieben bei Häusern/ Hotels
- Manche Seiten haben keine Hover-Animation, andere nicht z.B.: http://localhost:8080/booking/{id}  http://localhost:8080/events/{id}
- http://localhost:8080/hotels/{id} hovern verschiebt das obere Feld und überlagert mit der Karte
- Buttons auf den Haus Detail Seiten gehen einfach über Bild und Text
- Header ist teilwiese in verschiedenen Unterreitern unterschiedlich groß mit unterschiedlicher Schriftgröße

* Fehlende Features
- http://localhost:8080/contact-us hat keine Funktion/ es gibt keine Möglichkeit, um die Nachrichten einzusehen.
- Fehler-Messages fehlen auf manchen Seiten (z.B.: Login und Register)
- Booking Feature ist absolut gar nicht entahlten (Ich weiß das in der readme steht, dass es noch nicht "vollständig" implementiert ist, jedoch dachte ich das es einfach nur ein paar kleine Bugs gibt, anstatt das es gar nichts zu diesem Grund-Feature gibt.) 
- Es gibt generell wenig zusammenhängende Funktionalitäten zwichen den einzelnen Subsystemen (z.B. nahezu komplette Haus-Event Logik fehlt) 


* Interaktion mit der Anwendung (Usability)
- Sind es Ferienhäuser oder Hotels?
- Deutsch und Englisch vermischt
- Bedienung aufgrund fehlender Messages nicht intuitiv
